QUESTION 1:
Describe the changes/updates made in the deployed version.
(Character count: ~840 characters | Limit: 1,024)
--------------------------------------------------------------------------------
EventGenie AI is an end-to-end event planning application featuring:
1) AI Event Planner: Interactive multi-attribute setup with 1-click presets for weddings, birthdays, fests, and community events.
2) Deterministic Budget Planner: Allocates categories, calculates sub-items, and provides cost-saving tips programmatically in Python code—preventing LLM math hallucinations while keeping a 5% contingency reserve.
3) Dynamic Natural-Language Replanner: Modifies existing plans via chat assistant (e.g., budget cuts to ₹4,50,000 or guest changes) with trade-off analysis while strictly preserving completed task states.
4) Automated Timeline: Milestone tasks mapped to calendar deadlines with interactive checklist toggles.
5) Vendor Due-Diligence: Objective criteria, questions, and benchmark rates.
6) Creative Studio & Persistence: Curates themes, palettes, menus, cultural activities, and invitations, backed by JSON storage and Print/PDF export dossiers.

QUESTION 2:
Mention the Gen AI services utilized in the submission, and where did you utilize it?
(Character count: ~845 characters | Limit: 1,024)
--------------------------------------------------------------------------------
1) Google Gemini (gemini-2.5-flash / gemini-1.5-flash):
Integrated via lightweight HTTP REST and google-genai SDK for schema-enforced generation of creative event assets: theme concepts, color palette rationale, multi-course banquet menus (appetizers, live counters, royal mains), cultural celebration activities (Sangeet dance battles, Phoolon ki Holi), and 3-style invitation wordings (Formal, Playful, and WhatsApp Short).

2) Hybrid Architecture with Programmatic Separation:
Gemini's generative output is strictly decoupled from financial calculations. A deterministic Python engine handles all budget math, category allocations, and trade-off rebalancing to eliminate arithmetic errors.

3) Fallback Engine:
An internal rule-based engine activates automatically if API keys are absent, ensuring uninterrupted demoability.
